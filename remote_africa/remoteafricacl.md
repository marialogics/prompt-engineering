# Remote Jobs Application Development Guide

## Project Overview
Build a modern mobile application that connects job seekers with legitimate remote work opportunities worldwide (based on the websites shared to the application config file.) The platform should allow users to discover, apply for, and track remote jobs while enabling employers to post and manage vacancies.

## Core Objectives
- Provide a simple and fast remote job search experience.
- Aggregate and display verified remote job listings.
- Enable one-click job applications.
- Support user profiles, resumes, and job tracking.
- Deliver a secure, scalable, and responsive platform.

## User Roles

### Job Seeker
- Create and manage profile
- Upload resume/CV
- Search remote jobs
- Save favorite jobs
- Apply for vacancies
- Track application status
- Receive job alerts

### Employer
- Create company profile
- Post remote jobs
- Manage applications
- Review candidate profiles
- Shortlist candidates

### Administrator
- Manage users
- Approve job postings
- Moderate content
- View system analytics
- Handle reports and abuse cases
- Create a file to upload upcoming websites that accomodate remote job applications from Africa
