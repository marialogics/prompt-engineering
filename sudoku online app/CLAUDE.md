# Project: Sudoku
## What it does
To play Sudoku with friends online.

## Tech Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Vitest

## Design
- Dark mode by default
- Green accent (#34d399)

## Commands
- Install: npm install
- Start dev server: npm run dev
- Build: npm run build
- Test: npm run test

## Coding Rules
- Use TypeScript for all new files
- Prefer functional components
- Use named exports
- Keep components under /Users/ndinda/Documents/js projects/sudoku_app
- Do not use inline styles; use Tailwind classes

## Architecture
- /Users/ndinda/Documents/js projects/sudoku_app/pages for routes
- /Users/ndinda/Documents/js projects/sudoku_app/components for UI
- /Users/ndinda/Documents/js projects/sudoku_app/lib for helpers
- /Users/ndinda/Documents/js projects/sudoku_app/types for TypeScript interfaces

## Important Notes
- Use environment variables from .env.local
- Run tests before finalizing a change
